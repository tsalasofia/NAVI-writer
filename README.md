=====================
REQUIREMENTS (first time setup):
1. Install Python: https://www.python.org/ (Check "Add python.exe to PATH" during setup)
2. Install Ollama: https://ollama.com/
3. Open a command prompt and run (copy paste one by one):
    1)  ollama pull llama3.2     
    2)  ollama pull nomic-embed-text

HOW TO RUN THE APP:
1. Double-click "setup.bat" (Only the first time).
2. Double-click "run.bat" to start NAVI.ai.
   - Your web browser will open automatically with the interface -
